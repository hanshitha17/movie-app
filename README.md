# 🎬 Movie App

A modern movie search web application built using React and TMDB API.  
Users can search for movies, watch trailers, view ratings, and check where the movie is available to stream.

---

## 🚀 Features

- 🔍 Search movies by title  
- 🎬 View trending movies on homepage  
- 🎥 Watch trailers inside the app  
- ⭐ See movie ratings  
- 🎯 Check streaming availability (Netflix, Hotstar, Prime, etc.)  
- 🔁 Click logo to return to homepage  
- ✨ Clean UI with hover effects and animations  

---

## 🛠️ Tech Stack

- React.js  
- TMDB API  
- JavaScript (ES6)  
- CSS  

---

## 🔑 API Used

This project uses the TMDB (The Movie Database) API to fetch movie data.

## ⚙️ Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/your-username/movie-app.git
cd movie-app

### 2. Install dependencies

```bash
npm install

### 3. Add API key

Create a `.env` file in the root directory and add:

```bash
REACT_APP_TMDB_KEY=your_api_key_here

### 4. Run the app

```bash
npm start
